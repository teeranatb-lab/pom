# OCR ใบอนุญาตและการเชื่อมแผนที่
ผู้ริเริ่มแนวทาง: Teeranat Butda
สถานะ: สรุปข้อกำหนดจาก Athena-30 Blueprint v2.3 และบทสนทนา ไม่รับรองสถานะใช้งานจริงจากเครื่องหมายในเอกสาร

## กระบวนการ
รับภาพจากกล้องหรือไฟล์ → จัดลำดับหน้าและปรับภาพ → OCR → จับฟิลด์ตามแม่แบบ → เน้นจุดไม่แน่ใจ → ผู้ใช้แก้และยืนยัน → บันทึก → เชื่อมตำแหน่งกับแผนที่

OCR เป็นร่างข้อมูล ไม่ใช่หลักฐานว่าข้อความถูกต้องทั้งหมด ต้องเก็บภาพต้นทางและแยกข้อความที่อ่านได้ ข้อเสนอแก้ไข และข้อมูลที่ยืนยันแล้ว

## พิกัด
แยกคู่ E/N และตรวจช่วงค่าก่อนนำเข้า การคาดเดา Datum หรือ zone จากรูปแบบตัวเลขต้องถือเป็นข้อเสนอรอตรวจ ไม่เปลี่ยนเป็นข้อเท็จจริงโดยเงียบ ๆ ตรวจค่าที่แปลงกับจุดควบคุมและเก็บ residual เมื่อทำได้

## ความเชื่อมโยง
รายการใบอนุญาตเชื่อมกับตำแหน่งและรายละเอียดบนแผนที่ได้ โดยใช้ record ID ที่คงที่ กระบวนการตรวจข้อมูลซ้ำและวันหมดอายุควรอ้างข้อมูลที่ยืนยันแล้ว ไม่รวมเอกสารต่างฉบับเพียงเพราะชื่อคล้ายกัน

## สิทธิ์และการตรวจรับ
แยก Admin, Editor และ Viewer ตรวจสิทธิ์ฝั่งระบบและบันทึกการแก้ไข ทดสอบเอกสารหลายหน้า ภาพไม่ชัด ตัวเลขคล้ายกัน ข้อมูลขาด พิกัดสลับแกน และผู้ใช้ต่างสิทธิ์

เนื้อหานี้ไม่รวมข้อมูลผู้รับใบอนุญาต ภาพเอกสารราชการจริง หรือรายละเอียดบัญชี และไม่ให้สิทธิ์เผยแพร่ข้อมูลเหล่านั้น
