# Benchmark ที่แยกผลของสถาปัตยกรรมออกจากโมเดล
ผู้ริเริ่มกรอบและข้อกำหนด: Teeranat Butda
สถานะ: ข้อกำหนดทดลองวันที่ 5 พฤศจิกายน 2569 ผลทดลอง Runtime ยังไม่ยืนยันในชุดนี้

## เงื่อนไขเปรียบเทียบ
ใช้คลังข้อมูล โมเดลตอบ และงบ Context เดียวกันเมื่อเปรียบเทียบ BM25, Embedding, Hybrid Retrieval, Reranker และ Graph-based Retrieval เพื่อไม่ให้ความแตกต่างของโมเดลกลบผลของสถาปัตยกรรม

## กลุ่มคำถาม
ภาษาไทยและอังกฤษ การปฏิเสธ ความกำกวม ความสัมพันธ์ ทิศทาง เวลา และข้อจำกัดของเจตนา ครอบคลุม Canonical Resonance ที่ไม่อาศัยคำศัพท์ตรงกัน การคงข้อจำกัดเมื่อแก้คำสั่งเพียงบางส่วน และการปฏิเสธข้อสรุปที่ไม่มีหลักฐาน

## ตัวชี้วัด
Recall@5/20, nDCG@10, ความถูกต้องของคำตอบและหลักฐาน, อัตราข้ออ้างไร้หลักฐาน, การรักษาข้อจำกัด, latency p50/p95, RAM และต้นทุนต่อคำถาม

## หลักควบคุม
- ล็อกเกณฑ์ก่อนทดสอบ ไม่เปลี่ยนเกณฑ์หลังเห็นผล
- เก็บผลล้มเหลวและ Provenance
- ตรวจความพร้อม Runtime ก่อนทดลองจริง
- แยกผลตรวจเครื่องมือออฟไลน์ออกจากผล Benchmark ระบบจริง
- เมื่อรันจริงไม่ได้ ให้ระบุ NOT TESTED ไม่สร้าง PASS จำลอง
- ไม่แก้ Core 0 หรือ Canonical ต้นฉบับ

## ชุดที่เคยส่งมอบ
ข้อความส่งมอบวันที่ 5 พฤศจิกายนระบุ Benchmark Kit v1.0.0 มี 237 กรณี แบ่งพัฒนา 36 และทดสอบ 201 พร้อมผลตรวจเครื่องมือออฟไลน์ 9 รายการ ข้อมูลนี้เป็นรายงานในบทสนทนา ยังไม่ได้เปิดตรวจไฟล์ ZIP ซ้ำในรอบรวบรวมนี้ จึงไม่ถือเป็นการรับรองผลหรือความครบของไฟล์ปัจจุบัน
