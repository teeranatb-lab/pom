# BigMap ข้อมูลกลางและพิกัด
ผู้ริเริ่มแนวทาง: Teeranat Butda
สถานะ: ข้อกำหนดออกแบบและบทเรียนการใช้งาน ไม่ใช่ผลทดสอบซอฟต์แวร์รุ่นล่าสุด

## หน้าเดียวและข้อมูลชุดเดียว
คำสั่งวันที่ 3 ตุลาคม 2569 เปลี่ยนแนวคิดสี่รุ่นให้ใช้งานในหน้าเดียว โดยปุ่ม Modeler, Geo, Civil และ Pro เปลี่ยนเฉพาะ UI และเครื่องมือ ข้อมูลยังเป็นชุดเดิม

Object ID, Geometry, พิกัด, Layer, ความสัมพันธ์ และประวัติต้องไม่แตกเป็นข้อมูลใหม่เมื่อเปลี่ยนโหมด โมดูลที่ยังไม่รองรับวัตถุบางชนิดควรเก็บข้อมูลนั้นไว้ ไม่ลบทิ้งเมื่อบันทึกกลับ

## แยกโมเดลกลางจากตัวส่งออก
Scene/Object Model เป็นแหล่งข้อมูลกลาง แล้วใช้ adapter ส่งออกแต่ละรูปแบบ การเปิดไฟล์ปลายทางและความถูกต้องของข้อมูลต้องทดสอบจริง ไม่ถือว่าการเขียนไฟล์สำเร็จเท่ากับใช้งานได้

## พิกัดและ Datum
ก่อนแปลงต้องรู้ระบบพิกัดต้นทาง หน่วย แกน และ Datum รวมถึง UTM zone ที่ถูกต้อง ไม่ถือว่าตัวเลขที่ดูเหมือน UTM เป็น WGS84 เสมอ และไม่ถือว่าองศาทศนิยมบอก Datum ได้ด้วยตัวเอง

ประวัติการทำงานมีข้อมูล Indian 1975 / UTM Zone 48N และ WGS84 คนละชุด การนำเข้าต้องคงข้อมูลต้นทางและป้ายระบบพิกัดแยกกัน ไม่ใช้ค่าตั้งต้นเงียบ ๆ แทนข้อมูลที่ยังไม่ทราบ

## การตรวจ
- ตรวจลำดับ Easting/Northing หรือ latitude/longitude
- ตรวจตำแหน่งเทียบจุดควบคุมและภูมิประเทศ
- บันทึกวิธีแปลงและความคลาดเคลื่อนที่วัดได้
- ตัวเลขที่อ่านไม่ชัดจากภาพต้องระบุว่าไม่ชัด ไม่เติมความละเอียดเทียม
- การเปลี่ยนรูปแบบแสดงพิกัดต้องไม่ทำให้ตำแหน่งวัตถุเปลี่ยน

## ที่มา
บทสนทนา Universal Modeler วันที่ 3 ตุลาคม 2569 และงานนำเข้าพิกัดช่วงปลายตุลาคมถึงพฤศจิกายน 2569 สรุปเฉพาะหลักการ ไม่เผยแพร่ค่าพิกัดหรือเอกสารพื้นที่จริง
