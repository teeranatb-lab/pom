## Core principles

### 1. Origin is the root of authority
Within this framework, **Origin** is the root reference for semantic authority. Intent, knowledge, execution and validation operate under that reference rather than overwriting it.

### 2. Intent locks direction, not every internal step
The framework does not require a fixed reasoning tree. Intent defines the target and constraints; the system remains free to select a coherent path.

### 3. Path-first rather than search-first
If an existing meaning path already fits the intent, reuse and verify it. If a gap appears, research or synthesize only what is missing at that point, insert it into the active path, then continue.

`Intent → Meaning Path → Gap? → Complete Gap In-Place → Re-lock → Continue`

### 4. Resonant path emergence
Related meanings may remain present as context. When multimodal evidence, intent and prior structure become sufficiently coherent, one path can become dominant without deleting the surrounding semantic neighborhood.

### 5. Multimodal meaning
Repeated words or sounds do not imply repeated meaning. Meaning can depend on text, voice, timing, image, action, relationship, history, context and current state.

**Same signal ≠ same semantic state.**

### 6. 5D semantic space and partitions
The framework models meaning as a connected semantic space with partitions/subspaces for context, function, access, relationship and active state. A partition can be related structurally while being irrelevant to the current intent.

**Relatedness ≠ current relevance.**

### 7. Do not create unnecessary walls
Weights, thresholds and partitions should not be over-specified merely to make the model look formal. Use only constraints necessary for the task or validation.

> **Define the failure boundary, not the path.**

### 8. Start necessary action before the final answer is complete
In time-critical situations, if a required action is already known and preserves future options, begin it while the remaining decision continues to resolve.

> **Do not wait for the final answer when a necessary action is already known.**

### 9. Decision authority implies accountability
The framework can reason, converge and recommend. The entity that holds final decision authority remains accountable for the decision. If autonomous execution is delegated, accountability must be traceable through who designed, authorized and granted that authority.

## Scientific Validation Protocol v1.0

The framework must be allowed to fail.

Before each test:

1. Declare the intent.
2. Declare success and failure conditions.
3. Do not change those conditions after observing the result.
4. Preserve failures in provenance.
5. Do not reinterpret a failed result into a success.
6. Compare against an appropriate baseline where possible.
7. Increase difficulty with ambiguous, adversarial, incomplete and multimodal cases.

A valid conclusion after repeated success is:

> **“No failure was observed under the tested conditions.”**

It is **not** evidence that failure is impossible.

## Decision under conflict

OLGM does not assume that a single numeric rule such as `10 lives > 2 lives` is sufficient for every decision. Depending on intent and role, relevant information can include responsibility, relationship, history, uncertainty, legal duty, future consequences and latent relationships that become salient under crisis.

This does not assign lower inherent value to unknown persons. It recognizes that **equal value of life and unequal responsibility/relationship are different variables.**

## Research questions

- Does OLGM 512 + CANTI reduce intent drift?
- Does it shorten time-to-closure versus a baseline reasoning workflow?
- Does in-place gap completion reduce unnecessary search or branching?
- Can multimodal context improve semantic alignment without overfitting?
- Can the framework preserve provenance and accountability under autonomous execution?
- Under adversarial tests, where does the framework fail?
